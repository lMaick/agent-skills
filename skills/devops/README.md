# ⚙️ Skills de DevOps & Observabilidade

Área dedicada a automação de CI/CD, monitoramento, containers, infraestrutura e segurança.

### 📌 Skills Candidatas para Clonar / Adicionar
- **`github-actions-ci`**: Pipelines otimizados de lint, typecheck, teste e build com cache.
- **`sentry-observability`**: Rastreamento de exceções, distributed tracing e logs estruturados.
- **`docker-compose-deploy`**: Criação de ambientes locais e isolados com containers.
