# 🛡️ Skills de QA & Testes

Área dedicada a qualidade de software, testes automatizados, mutação e análise de regressão.

### 📌 Skills Candidatas para Clonar / Adicionar
- **`playwright-e2e`**: Padrões de testes ponta a ponta para Next.js (mobile viewports, emulação touch).
- **`vitest-integration`**: Testes de integração para DAL e lógica financeira com cobertura de branches.
- **`stryker-mutation`**: Testes de mutação para garantir que os testes quebram quando o código quebra.
